Syndicate Gateway
সম্পূর্ণ সেটআপ গাইড

একদম শূন্য থেকে সাইট লাইভ করা পর্যন্ত — প্রতিটা ধাপ। ক্রম অনুযায়ী করুন, কোনোটা বাদ দেবেন না।

মোট সময়: ২০–৩০ মিনিট
খরচ: ০ টাকা (সব ফ্রি)
যা লাগবে: একটা GitHub অ্যাকাউন্ট, একটা Appwrite অ্যাকাউন্ট, আর এই ফোল্ডারের ফাইলগুলো।

📦 এই প্যাকেজে যা আছে

index.htmlমূল ল্যান্ডিং পেজ
signup.htmlঅ্যাকাউন্ট তৈরি
login.htmlলগইন
dashboard.htmlড্যাশবোর্ড (লগইন লাগে)
404.htmlভুল লিংক → হোমে ফেরত
CNAMEডোমেইন সংযোগ
.nojekyllPages ঠিকমতো চলার জন্য
⚠️ CNAME ও .nojekyll — এই দুটো বিশেষ ফাইল (এক্সটেনশন নেই / লুকানো)। অনেকে এগুলো আপলোড করতে ভুলে যায় — তখনই সাইট ভাঙে। এগুলো অবশ্যই লাগবে।

1GitHub অ্যাকাউন্ট ও Repository

১.১ — অ্যাকাউন্ট (আগে থাকলে বাদ দিন)

  1. github.com এ যান → Sign up
  2. ইমেইল, পাসওয়ার্ড, ইউজারনেম দিয়ে অ্যাকাউন্ট খুলুন

১.২ — নতুন Repository বানান

  1. উপরে ডানে + → New repository
  2. Repository name: Syndicate-Gateway
  3. Public সিলেক্ট করুন জরুরি
  4. বাকি সব খালি রাখুন (README/gitignore টিক দেবেন না)
  5. Create repository চাপুন
🚫 Public না করলে GitHub Pages ফ্রিতে চলবে না → সাইট 404 দেখাবে। প্রাইভেট repo + Pages একসাথে পেতে GitHub Pro (পেইড) লাগে।

2ফাইল আপলোড

  1. নতুন repo-র পেজে "uploading an existing file" লিংক চাপুন
    (অথবা Add file → Upload files)
  2. এই ফোল্ডারের ৭টা ফাইল সিলেক্ট করুন:
    index.html signup.html login.html dashboard.html 404.html CNAME .nojekyll
  3. ⚠️ সরাসরি repo-র root-এ — কোনো ফোল্ডারের ভেতরে নয়
  4. নিচে Commit changes চাপুন
📱 ফোনে .nojekyll বা CNAME আপলোড না হলে — আলাদা করে বানান:

CNAME বানাতে: Add file → Create new file → নাম: CNAME → ভেতরে লিখুন: syndicategateway.com → Commit

.nojekyll বানাতে: Add file → Create new file → নাম: .nojekyll → ভেতরে কিছু লিখবেন না (খালি) → Commit

3GitHub Pages চালু সবচেয়ে জরুরি

এই ধাপটাই আগে বাদ পড়ায় সাইট 404 দেখাচ্ছিল। মন দিয়ে করুন।

  1. repo-তে উপরে Settings (⚙️) চাপুন
  2. বাঁ মেনুতে নিচে স্ক্রল করে Pages চাপুন
  3. Source: "Deploy from a branch" সিলেক্ট করুন
  4. Branch: main সিলেক্ট করুন
  5. Folder: / (root) সিলেক্ট করুন
  6. Save চাপুন
  7. একটু নিচে Custom domain বক্সে লিখুন: syndicategateway.com
  8. Save চাপুন
  9. Enforce HTTPS অপশন এলে টিক দিন (DNS চেক হতে কিছু সময় লাগতে পারে)
✅ ঠিকভাবে হলে কিছুক্ষণ পর উপরে লেখা আসবে: "Your site is live at https://syndicategateway.com"

4ডোমেইন DNS চেক যদি দরকার হয়

আপনার syndicategateway.com ডোমেইনটা যেখান থেকে কিনেছেন (GoDaddy, Namecheap ইত্যাদি), সেখানে DNS রেকর্ড GitHub-এর দিকে পয়েন্ট করা থাকতে হবে। আগে যেহেতু সাইট চলছিল, এটা সম্ভবত করাই আছে। যদি ধাপ ৩-এর পরও ডোমেইন কাজ না করে, ডোমেইন প্রোভাইডারে এই রেকর্ডগুলো থাকা দরকার:

A রেকর্ড (host: @) → এই ৪টা IP:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

CNAME রেকর্ড (host: www) → syndicategateway.github.io

5Appwrite সংযোগ চেক

signup/login কাজ করার জন্য Appwrite-এ আপনার ডোমেইন যোগ থাকতে হবে। (Project ID ও Endpoint কোডেই বসানো আছে — নতুন কিছু লাগবে না।)

  1. cloud.appwrite.io → আপনার project খুলুন
  2. নিচে Integrations → Platforms
  3. এই দুটো hostname আছে কিনা দেখুন:
    syndicategateway.com
    www.syndicategateway.com
  4. না থাকলে: Add platform → Web → hostname দিন → Create
কোডে বসানো সেটিং (পরিবর্তনের দরকার নেই):
Endpoint: https://sgp.cloud.appwrite.io/v1
Project ID: 6a271e0d00298cb271d8

6টেস্ট

  1. ধাপ ৩-এর পর ৫–১০ মিনিট অপেক্ষা করুন (Pages তৈরি হতে সময় লাগে)
  2. Chrome-এ incognito ট্যাব খুলুন (⋮ → New incognito tab) — পুরনো cache এড়াতে
  3. syndicategateway.com খুলুন → ল্যান্ডিং পেজ আসবে
  4. Start Building চাপুন → signup পেজ
  5. নাম + ইমেইল + পাসওয়ার্ড (৮+ অক্ষর) → Create account
  6. সফল হলে → dashboard-এ যাবে, "Welcome, [নাম]" দেখাবে
  7. যাচাই: Appwrite → Auth সেকশনে নতুন ইউজার দেখা যাবে 🎉

✅ চূড়ান্ত চেকলিস্ট

  • repo নাম Syndicate-Gateway, Public
  • ৭টা ফাইল root-এ আপলোড (CNAME ও .nojekyll সহ)
  • Settings → Pages → Source = main / root, Saved
  • Custom domain = syndicategateway.com, Saved
  • "Your site is live at..." লেখা দেখা যাচ্ছে
  • Appwrite-এ দুটো hostname যোগ করা
  • incognito-তে সাইট খুলছে ও signup কাজ করছে

🔧 সমস্যা হলে

404 দেখায়:
→ repo Public আছে তো? (ধাপ ১)
→ Settings → Pages-এ Source = main branch সেট আছে তো? (ধাপ ৩)
→ CNAME ফাইল আছে তো, ভেতরে ঠিক syndicategateway.com?
→ ৫–১০ মিনিট অপেক্ষা করেছেন তো?
সাদা/খালি পেজ:
→ সব ফাইল root-এ আছে তো, ফোল্ডারের ভেতরে নয়?
→ .nojekyll ফাইল আপলোড হয়েছে তো?
signup-এ লাল error:
→ Appwrite-এ hostname যোগ আছে তো? (ধাপ ৫)
→ error-এ "CORS" থাকলে — hostname ঠিক মেলেনি, ধাপ ৫ আবার দেখুন
→ পাসওয়ার্ড ৮ অক্ষরের কম দিলে error দেবে — বড় পাসওয়ার্ড দিন
মনে রাখবেন: এটা একটা অ্যাকাউন্ট সিস্টেম (signup/login/dashboard) — ডেটাবেস ছাড়া। ব্যালেন্স/ট্রানজেকশন এখন স্যাম্পল ডেটা। ভবিষ্যতে আসল ট্রানজেকশন সেভ করতে চাইলে Appwrite Database যোগ করতে হবে — সেটা আলাদা ধাপ।

যেকোনো ধাপে আটকে গেলে — যে স্ক্রিনে আটকেছেন তার স্ক্রিনশট দিন, সমাধান বলে দেওয়া হবে।
